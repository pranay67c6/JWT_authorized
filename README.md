Experiment 11 – JWT Authorized Endpoint

📌 Description

This project demonstrates authentication and authorization using JSON Web Tokens (JWT) in a Node.js application.

✨ Features

User authentication
JWT token generation and verification
Protected API endpoints
Secure access to authorized resources
🛠️ Technologies Used

Node.js
Express.js
JavaScript
JSON Web Token (JWT)
🚀 How to Run

Install Node.js.
Open the project folder in a terminal.
Install dependencies: npm install
Start the application: node app.js
Test the authentication and protected endpoints using Postman.
🎯 Objective

To understand how JWT authentication works and how to protect API endpoints from unauthorized access.

✅ Expected Outcome

A working application that verifies JWT tokens and allows access to protected endpoints only to authorized users.
